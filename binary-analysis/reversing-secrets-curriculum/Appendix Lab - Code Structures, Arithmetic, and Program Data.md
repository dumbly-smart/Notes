# Appendix Lab — Code Structures, Arithmetic, and Program Data

Use the book’s appendices as a repeated pattern-recognition laboratory.

## Track A — code structures

Recover conditionals, short-circuit logic, loops, switches, recursion, calls, class methods, virtual dispatch, exceptions, and optimized variants.

## Track B — compiled arithmetic

Recover signed/unsigned multiply/divide, shifts, strength reduction, constant division, modulo, fixed-width overflow, and floating-point/SIMD transformations. Validate with boundary values.

## Track C — program data

Infer globals, stack locals, arrays, structures, unions, strings, pointers, lists, trees, vtables, and object lifetime from widths/offsets/consumers.

## Completion

Produce 50 pattern cards. Each contains source-built example, stripped optimized listing, recovered pseudocode, invariant, compiler variation, edge case, and a common misreading.
